## Architecture Decisions

### Client-only auth guard — KEPT
Firebase auth state yaşıyor browser'da. `(app)/layout.tsx` korumalı route grubu. API route'lar `requireUser()` ile token doğrular.

### Service layer separation — KEPT
API routes (`src/app/api/`) sadece HTTP: parse, auth, response. İş mantığı `src/services/` altında `server-only` ile.

### Standardized API responses — KEPT
`{ data }` başarı, `{ error: { message, code, details? } }` hata. Helpers: `src/lib/api/response.ts`.

### AI reuses existing proxy — KEPT
Tüm AI çağrıları `callAiProxy()` üzerinden gider. Yeni kod sadece retro-spesifik prompt engineering.

### Cards / Notes separate collection — NEW
Kartlar `cards` koleksiyonunda, retroda embedded değil. Her kart güncellenmesi retroyu yeniden yazmaz.

### Phase-driven UI + server guards — NEW
`phase` field (`write | vote | actions | closed`) hem UI'ı hem server validation'ı yönetir. Kart ekleme sadece `write` fazında, oylama sadece `vote` fazında.

### Actions standalone collection — NEW
`actions` koleksiyonu `retroId` ile bağlı. Team Board sorgusu ve carry-over için ayrı koleksiyon gerekli.

### Anonymous participants via sessionId — NEW
Katılımcılar Firebase anonymous auth yerine frontend'de `crypto.randomUUID()` ile üretilmiş `sessionId` kullanır. Bu `sessionId` localStorage'da saklanır. Anonim oylama ve kart yazarı bu ID ile tanımlanır.

### Polling over WebSocket — NEW
5 saniyelik `setInterval` polling ile retro durumu güncellenir. WebSocket karmaşıklığı bu hackathon için kabul edilmez risk.

### Magic link via token — NEW
Aksiyon oluşturulurken `magicToken` (UUID v4, 48 saat geçerli) kaydedilir. Deadline maili bu token ile kişiye özel URL içerir. Token doğrulaması login gerektirmez.

### Jira API Token (no OAuth) — NEW
Kullanıcı kendi Jira API token'ını ayarlar sayfasından girer. `node:crypto` AES-256 ile şifrelenerek MongoDB'ye kaydedilir. OAuth bu hackathon'da kapsam dışı.

## API Routes

Tüm route'lar `requireUser()` ile korunur (magic link route'ları hariç).

### Retro

| Method | Path | Açıklama |
|--------|------|----------|
| POST | `/api/retros` | Retro oluştur (title, timerMinutes, votesPerUser, sendSummaryMail?) |
| GET | `/api/retros` | Kullanıcının retrolarını listele |
| GET | `/api/retros/[id]` | Retro detayı + phase bilgisi |
| PATCH | `/api/retros/[id]/phase` | Phase geçişi (sadece moderatör) |

### Cards (Sticky Notlar)

| Method | Path | Açıklama |
|--------|------|----------|
| POST | `/api/retros/[id]/cards` | Kart ekle (column, content, sessionId) |
| GET | `/api/retros/[id]/cards` | Kartları listele (phase'e göre filtrelenmiş) |

| Method | Path | Açıklama |
|--------|------|----------|
| POST | `/api/retros/[id]/votes` | Grup oyu kaydet (groupId + sessionId, max votesPerUser) |
| GET | `/api/retros/[id]/votes` | Session oy durumu (votesUsed, votesRemaining) |

### AI

| Method | Path | Açıklama |
|--------|------|----------|
| POST | `/api/retros/[id]/ai/group` | AI gruplama — kartları kümeler, başlık önerir |

| Method | Path | Açıklama |

| POST | `/api/retros/[id]/actions` | Aksiyon oluştur → mail veya Jira tetikler |

## Component Architecture

### Retro Board (`/retros/[id]`)

- **PhaseBar** — Ant Design `Steps`. Moderatör "Sonraki Aşama" butonu görür.
- **TimerDisplay** — Geri sayım sayacı. `write` fazında aktif.
- **ColumnLayout** — 3 kolon: Mad (kırmızı) | Sad (mavi) | Glad (yeşil)
- **CardList** — Kolona göre kartları render eder. `vote` fazında oy sayısına göre sıralı.
- **StickyCard** — Ant Design `Card`, renkli sol border. `write` fazında sadece kendi kartı görünür.
- **AddCardForm** — Text input, sadece `write` fazında aktif.
- **VoteButton** — `vote` fazında görünür. `votedBy.includes(sessionId)` ile highlight.
- **AiGroupPanel** — `vote` fazı sonunda AI kümeleri gösterir.
- **ActionSuggestionPanel** — `actions` fazında AI taslakları + form (sahip, deadline, tip).

### Dashboard (`/dashboard`)

- **RetroMemoryWidget** — Son retronun özet kartı: ✅/⏳/❌ sayıları + açık aksiyon listesi.
- **CarryOverBanner** — Ant Design `Alert`. Yeni retro açılırken bitmemiş aksiyonlar.

### Action Update Page (`/action-update/[token]`)

- Auth yok. Token doğrulanır, üç seçenek sunulur: Done / In Progress / Failed.
- `Failed` → textarea (sebep). `In Progress` → datepicker.

## FE ↔ BE Communication

- **Pattern:** REST API (`fetch` + `Authorization: Bearer <token>`)
- **Auth:** Her istek `getIdToken()` ile Firebase token alır, header'a ekler
- **Polling:** Retro board durumu 5 saniyede bir `GET /api/retros/[id]` ile güncellenir
- **Error handling:** API hataları `{ error: { message, code } }` formatında, UI'da `message.error()` ile gösterilir
- **Response format:** `{ data: T }` başarı, `{ error: ApiError }` hata

```typescript
// Standart fetch helper pattern (dashboard/page.tsx'ten)
const token = await getIdToken();
const res = await fetch("/api/retros", {
  headers: { Authorization: `Bearer ${token}` },
});
const body: unknown = await res.json();
if (!res.ok) { /* handle error */ }
const parsed = retroListSchema.safeParse(body);
```

## Jira Integration

```typescript
// src/services/jira.ts
export async function createJiraTicket(params: {
  domain: string;
  token: string;      // decrypted
  projectKey: string;
  summary: string;
  description: string;
}): Promise<{ url: string; id: string }> {
  const res = await fetch(`https://${params.domain}/rest/api/3/issue`, {
    method: "POST",
    headers: {
      Authorization: `Basic ${Buffer.from(`user@example.com:${params.token}`).toString("base64")}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      fields: {
        project: { key: params.projectKey },
        summary: params.summary,
        description: { type: "doc", version: 1, content: [{ type: "paragraph", content: [{ type: "text", text: params.description }] }] },
        issuetype: { name: "Task" },
        labels: ["retro"],
      },
    }),
  });
  // ...
}
```

Token şifreleme: `node:crypto` AES-256-CBC. Key: `JIRA_TOKEN_ENCRYPTION_KEY`.
