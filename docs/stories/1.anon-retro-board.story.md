# Story 1: Anonim Retro Board (Timer'lı)

**Status**: Ready for Review
**Priority**: Must
**Epic**: Retro Board
**Created**: 14 Mayıs 2026

---

## Story

**As a** moderatör (Scrum Master / takım lideri),
**I want** anonim sticky not yazma aşamasını timer ile yönetebilmek ve timer dolunca tüm notların ekrana açılmasını sağlamak,
**so that** ekip üyeleri birbirinden etkilenmeden düşüncelerini özgürce paylaşabilsin ve retro yapılandırılmış şekilde ilerlesin.

---

## Acceptance Criteria

1. Moderatör yeni bir retro oluşturabilir; retro adı ve timer süresi (dakika cinsinden) girilir.
2. Ekip üyelerine paylaşılabilir bir retro linki oluşturulur; link ile katılan kullanıcılar anonim olarak tanımlanır (isim görünmez).
3. Katılımcılar Mad / Sad / Glad kolonlarına sticky not ekleyebilir; yazma aşamasında başkalarının notları görünmez.
4. Moderatör timer'ı başlatır; geri sayım tüm katılımcılara canlı olarak gösterilir.
5. Timer sıfırlandığında yazma aşaması otomatik kapanır ve tüm notlar tüm katılımcılara açılır.
6. Moderatör timer dolmadan da "Aşamayı Bitir" ile yazma aşamasını kapatabilir.
7. Edge case: Katılımcı not yazmadan timer dolarsa, o kullanıcının notu olmaması normal kabul edilir; hata gösterilmez.

## Dev Notes

**Relevant files:**

- `src/app/(app)/retros/new/page.tsx` — Retro oluşturma sayfası
- `src/app/(app)/retros/[id]/page.tsx` — Aktif retro board sayfası
- `src/app/api/retros/route.ts` — Retro CRUD API
- `src/app/api/retros/[id]/cards/route.ts` — Sticky not API
- `src/lib/mongodb/client.ts` — MongoDB bağlantısı
- `src/contexts/auth-context.tsx` — Auth state

**Patterns to follow:**

- MongoDB bağlantısı için `src/lib/mongodb/client.ts` kullan
- API route'larda Zod ile input validation yap
- Auth guard için `(app)/layout.tsx` pattern'ını takip et
- UI primitifleri için Ant Design kullan (`Form`, `Button`, `Input`, `Card`)

**API / Data:**

- `POST /api/retros` — `{ title, timerMinutes, votesPerUser }` → retro oluşturur
- `GET /api/retros/[id]` — Retro durumu + phase bilgisi
- `POST /api/retros/[id]/cards` — `{ column: 'mad'|'sad'|'glad', content, sessionId }` → not oluşturur
- `GET /api/retros/[id]/cards?sessionId=xxx` — Kartları listeler (phase'e göre filtrelenmiş)
- `PATCH /api/retros/[id]/phase` — `{ phase, startTimer? }` → aşama günceller

**MongoDB Model — Retro:**
```
{
  _id, title, timerMinutes, timerEndsAt, phase, votesPerUser,
  createdBy, teamId, createdAt, updatedAt
}
```

**MongoDB Model — Card:**
```
{
  _id, retroId, column, content, sessionId, votes, votedBy,
  groupId, groupTitle, createdAt
}
```

**Environment variables needed:**

- `MONGODB_URI` — MongoDB Atlas bağlantı stringi
