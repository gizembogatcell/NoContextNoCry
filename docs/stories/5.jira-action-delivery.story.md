# Story 5: Jira Aksiyon Teslimi (API Token)

**Status**: Cancelled
**Priority**: Should
**Epic**: Bildirim Sistemi
**Created**: 14 Mayıs 2026

---

## Story

**As a** moderatör,
**I want** aksiyonun tipini "Jira" seçtiğimde bu aksiyonun otomatik olarak Jira'da ticket açmasını ve linki uygulama içinde görmesini,
**so that** ekip zaten her gün baktığı Jira board'unda retro aksiyonlarını takip edebilsin.

---

## Acceptance Criteria

1. Uygulama ayarlarında kullanıcı Jira domain, API token ve proje key girebilir; bu bilgiler güvenli şekilde kaydedilir.
2. Aksiyon tipi "Jira" olarak onaylandığında Jira REST API v3 ile seçili projede yeni bir ticket açılır.
3. Ticket `label: retro` ve ticket açıklaması AI tarafından yazılır (aksiyon bağlamını içerir).
4. Oluşturulan Jira ticket'ının linki ve ticket ID'si uygulamamızda aksiyonun yanında gösterilir.
5. Edge case: Jira API'dan hata gelirse (401, 404 vb.) kullanıcıya anlamlı hata mesajı gösterilir; aksiyon yine de uygulamamızda kaydedilir.
6. Edge case: Jira ayarları yapılmamışken "Jira" tipi seçilirse kullanıcı ayarlar sayfasına yönlendirilir.

## Dev Notes

**Relevant files:**

- `src/services/jira.ts` — Jira API wrapper (oluşturulacak)
- `src/app/(app)/settings/page.tsx` — Jira ayarları (oluşturulacak)
- `src/app/api/settings/jira/route.ts` — Jira ayarları API (oluşturulacak)
- `src/app/api/actions/route.ts` — Story 3'te oluşturuldu

**Patterns to follow:**

- API token düz metin MongoDB'de saklanmaz; Node.js `crypto` ile AES-256 şifrelenir
- Hata handling: Jira API 4xx/5xx → `console.error` + toast, aksiyon `jiraError` alanına hata mesajı yazılır

**API / Data:**

- Jira REST API: `POST https://{domain}/rest/api/3/issue`
  ```json
  {
    "fields": {
      "project": { "key": "{projectKey}" },
      "summary": "{aksiyon metni}",
      "description": { "type": "doc", "version": 1, "content": [...] },
      "issuetype": { "name": "Task" },
      "labels": ["retro"]
    }
  }
  ```
- Action model güncellemesi: `jiraTicketUrl`, `jiraTicketId`, `jiraError`

**MongoDB Model — JiraSettings:**
```
{
  _id, userId, domain, encryptedToken, projectKey, createdAt
}
```

**Environment variables needed:**

- `JIRA_TOKEN_ENCRYPTION_KEY` — API token şifreleme anahtarı (32 byte)
