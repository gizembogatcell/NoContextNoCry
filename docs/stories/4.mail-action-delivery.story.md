# Story 4: Mail Aksiyon Teslimi (AI Üretimli, Görsel)

**Status**: Approved
**Priority**: Must
**Epic**: Bildirim Sistemi
**Created**: 14 Mayıs 2026

---

## Story

**As a** aksiyon sahibi (ekip üyesi),
**I want** aksiyonum atandığında AI tarafından yazılmış, eğlenceli ve görsel bir HTML mail almak,
**so that** ne yapmam gerektiğini, neden önemli olduğunu ve deadline'ımı net biçimde anlayayım.

---

## Acceptance Criteria

1. Aksiyon tipi "Mail" olarak onaylandığında sahibe otomatik atama maili gönderilir.
2. Mail içeriği AI tarafından üretilir: aksiyonun bağlamı (küme adı, oy sayısı, kaçıncı retroda çıktığı), kişiselleştirilmiş selamlama ve motivasyon cümlesi içerir.
3. Mail görsel HTML şablonuyla gönderilir: renkli başlık, aksiyon kartı, emoji, CTA butonu ("Uygulamada Görüntüle").
4. Mail gönderimi başarıyla tamamlandığında aksiyonun `mailSentAt` alanı güncellenir.
5. Edge case: Mail gönderimi başarısız olursa hata loglanır, moderatöre UI'da uyarı gösterilir; aksiyon yine de kaydedilir.

## Dev Notes

**Relevant files:**

- `src/services/mailer.ts` — Resend wrapper (oluşturulacak)
- `src/services/mail-content.ts` — AI içerik üretici (oluşturulacak)
- `src/templates/action-assigned.html.ts` — HTML mail şablonu (oluşturulacak)
- `src/app/api/actions/route.ts` — Story 3'te oluşturuldu; mail gönderimi buradan tetiklenir

**Patterns to follow:**

- Mail gönderimi `POST /api/actions` içinde aksiyon kaydedildikten sonra fire-and-forget olarak tetiklenir
- Hata durumunda `console.error` ile logla, kullanıcıya toast notification göster
- HTML şablonda inline CSS kullan (e-posta istemcileri harici CSS desteklemez)

**API / Data:**

- Resend API: `resend.emails.send({ from, to, subject, html })`
- Action model güncellemesi: `mailSentAt: Date`

**Environment variables needed:**

- `RESEND_API_KEY` — Resend API anahtarı
- `RESEND_FROM_EMAIL` — Gönderen e-posta adresi (ör. `noreply@retroflow.app`)
- `NEXT_PUBLIC_APP_URL` — CTA butonundaki uygulama URL'i
