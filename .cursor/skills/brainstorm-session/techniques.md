# Brainstorming Techniques Reference

Use these techniques during Step 2 of the brainstorm-session skill.
Apply 3 techniques per session. Choose based on the problem type.

---

## For Well-Defined Problems

### What-If Scenarios

Ask one provocative question, get their response, then ask another.
Examples:

- "What if this solved itself automatically?"
- "What if the user never had to think about this?"
- "What if we removed the most annoying step entirely?"

### SCAMPER Method

Go through one letter at a time, wait for ideas before moving on.

- **S**ubstitute — What could we replace in the current solution?
- **C**ombine — What two things could we merge?
- **A**dapt — What from another industry could we adapt here?
- **M**odify / Magnify — What if we made one feature 10x bigger?
- **P**ut to other uses — How else could this be used?
- **E**liminate — What could we remove entirely?
- **R**everse / Rearrange — What if we reversed the workflow?

### Reversal / Inversion

Pose the reverse question, let them work through it.

- "How would we make this problem WORSE?"
- "What would the worst possible solution look like?"
- Then: "What's the opposite of each of those ideas?"

---

## For Vague Problems

### Five Whys

Ask "Why?" and wait for their answer before asking the next "Why?"
Start with: "Why does this problem exist?"
Ask "Why?" 5 times, drilling deeper each time.
The 5th answer is often the root cause.

### First Principles Thinking

Ask: "What are the absolute fundamental requirements here?"
Guide them to strip away assumptions:

- "What do we know for certain is true about this problem?"
- "If we were building this from scratch with no constraints, what would we keep?"

### Assumption Reversal

List the core assumptions about the problem, then challenge each one.

- "We assume users want X — what if they don't?"
- "We assume we need Y — what if we didn't?"

---

## For Creative / Lateral Problems

### Random Stimulation

Give one random word or image, ask them to make connections.
Examples: "clock", "ocean", "library", "game show"
Ask: "How does [random word] relate to our problem? Force a connection."

### Forced Relationships

Connect two unrelated concepts and ask them to find the bridge.
Example: "How is our problem like a pizza delivery service?"
Ask: "What would we borrow from that model?"

### Role Playing

Ask them to brainstorm from different stakeholder perspectives.

- "How would a 10-year-old solve this?"
- "How would a bank solve this?"
- "How would the laziest possible user want this to work?"

### Time Shifting

- "How would you solve this in 1995? With no internet?"
- "How would this work in 2035 with AI everywhere?"
- "What if you had only 1 hour to build a solution?"

### Resource Constraints

- "What if you had $0 budget?"
- "What if the team was just one person for one day?"
- "What if you could only use tools that already exist?"
